Soft Summer

柔夏 Cool / Soft / Muted Personal Report

柔和、偏冷、低饱和的夏季型

你的色彩气质像被一层轻雾柔化过，适合灰调粉彩、莫兰迪色和低对比配色。过亮、过暖、过黑都会让脸显脏或显硬。

UNDERTONE 偏冷
VALUE 中等明度
CHROMA 低饱和

Color Temperament

柔夏不是强烈抢眼的美，而是安静、细腻、有空气感的美。带灰度、带冷感、柔和过渡的颜色，会让脸看起来更干净、更有质感。

Keywords

雾面 / 清冷 / 柔软 / 淡雅 / 低调高级

Wearing Notes

灰粉、雾蓝、鼠尾草绿、灰紫让脸安静细腻。全身同色系或相近色搭配最稳，避免大面积强撞色。黑白强对比容易显硬，可以用灰白、烟灰、雾蓝替代。

Makeup Notes

Base

冷调粉底，避免黄调，轻薄柔雾。

Eyes

灰棕、浅紫灰、烟灰。适合低饱和轻烟熏。

Blush

冷粉、灰玫瑰。薄扫出自然血色。

Lips

裸粉、玫瑰豆沙、灰粉。柔雾质地更顺。

判断依据

  • 整体对比度偏低，五官边界柔和。
  • 肤色可能偏粉、冷黄或橄榄，但共同点是容易被强色抢走气色。
  • 银饰、雾面金属比亮黄金更自然。

Colors To Avoid

亮橙 金黄 纯黑

黑白强对比对柔夏通常偏硬，建议用灰白、烟灰、雾蓝替代。

Soft Summer Rule 颜色越安静，人越清透。
